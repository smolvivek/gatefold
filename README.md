# Gatefold

A presentation and funding tool for creative professionals. Turn a film, game, ad campaign, or any creative project into one structured, shareable pitch — without flattening it into a generic deck.

## The problem

Pitching creative work is still done with the wrong tools. A filmmaker finishes a script, builds a deck in a generic presentation app, emails it around, and gets feedback back through scattered texts, voice memos, and comment threads. There's no single source of truth, no version history, and no way to raise money without leaving the platform entirely. Every tool treats a creative pitch like a corporate slide deck — optimized for polish, not for clarity of vision.

## What Gatefold does

Every project gets one shareable link. That link holds:

- **Eight required fields** — logline, synopsis, genre & format, director's vision, cast & characters, budget range, production status, and key team. Enough structure that any pitch is intelligible, whatever the medium.
- **Up to eighteen optional sections** — locations, art direction, stunts, sound design, schedule, and more — so a filmmaker, a game developer, and a photographer can use the same tool without the tool pretending they're building the same thing.
- **The Flow** — a horizontal-scroll sequence of beats with images, video, and optional audio, built to let someone *feel* a project's arc rather than read a bullet list of it.
- **Version history** — every revision persists, so a producer who saw v1 can see exactly what changed by v4.
- **Funding, built in** — an optional "Support this Project" section with a funding goal and direct payment processing. No separate crowdfunding platform, no separate link to manage.

## What it isn't

Not a deck generator. Not a marketplace. No creator rankings, no algorithmic scoring, no social feed. AI assists when explicitly asked — summarizing, suggesting, generating a reference image — and never overwrites what a creator wrote. The manual version is always the default.

## Status

Early-stage build, in active development. Next.js (App Router) on Supabase and Stripe/Razorpay, deployed on Vercel.

## Design

Near-black canvas, two functional colors, three typefaces. Built against the idea that negative space is an instrument panel, not empty space — informed by Dieter Rams' restraint and the Casio F91W's "nothing on it that isn't doing a job."
